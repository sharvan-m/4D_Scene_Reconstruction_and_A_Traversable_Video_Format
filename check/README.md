# Validation & Visual Diagnostics (`check/`)

This directory stores visual verification checks, camera pair alignments, and geometry tests produced during the reconstruction pipeline:

- `pair_01.png`: Stereo / multi-view camera verification alignment check (Pair 1).
- `pair_02.png`: Stereo / multi-view camera verification alignment check (Pair 2).

These assets serve as visual benchmark assertions confirming that multi-view pose calibration was properly aligned prior to Gaussian optimization.
